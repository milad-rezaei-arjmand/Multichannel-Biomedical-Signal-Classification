# Results

This directory separates **archived reported results** from outputs generated by the cleaned public pipeline.

## Archived Result Document

[`final_metrics.md`](final_metrics.md) preserves the previously reported experiment summary.

Those metrics are retained as historical project results. They are not presented as a fresh reproduction of the current public implementation because the original dataset is not distributed and the archived feature-count description does not match the current tracked feature extractor.

## Current Pipeline Outputs

The cleaned training pipeline writes generated files to:

```text
outputs/evaluation/
```

including:

```text
metrics.json
confusion_matrix.csv
classification_report.txt
```

Model checkpoints and training metadata are written to:

```text
outputs/checkpoints/
```

including:

```text
catboost_model_0.cbm
catboost_model_1.cbm
catboost_model_2.cbm
feature_selector.pkl
training_metadata.json
```

The `outputs/` directory is intentionally ignored by Git.

## Evaluation Metrics

The public evaluation module reports:

- Accuracy
- Macro precision
- Macro recall
- Macro F1-score
- Weighted F1-score
- Confusion matrix
- Classification report

Class ordering is now passed explicitly to scikit-learn evaluation functions to prevent label/report mismatches.
